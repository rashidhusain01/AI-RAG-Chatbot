# 🤖 AI RAG Chatbot Frontend

A modern and responsive frontend for the AI-powered Retrieval Augmented Generation (RAG) Chatbot. Built with React and Vite, the application provides an intuitive interface for uploading PDF documents and asking AI-powered questions based on their content.

The frontend communicates with a FastAPI backend and displays AI-generated responses in real time.

---

## 🚀 Features

- Modern and responsive UI
- Upload PDF documents
- Ask questions about uploaded documents
- AI-generated responses
- Fast communication with FastAPI backend
- Loading indicators and error handling
- Clean and user-friendly interface

---

### Frontend

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/rashidhusain01/AI-RAG-Chatbot-Frontend.git
```

### 2. Navigate to Project

```bash
cd AI-RAG-Chatbot-Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```

---

## 🔗 Backend API

Make sure the FastAPI backend is running before starting the frontend.

Default Backend URL:

```
http://localhost:8000
```

For production deployment, update the API URL with your deployed backend endpoint.
